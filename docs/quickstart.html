Get started

Quickstart

Run Pharo-Coder locally and generate your first Pharo class.

1. Install Ollama

Download Ollama from ollama.com/download (macOS, Linux, Windows). On Linux:

curl -fsSL https://ollama.com/install.sh | sh

2. Run a model

Pharo-Coder 1.0 7B is the recommended default: it needs about 5 GB of memory with the default 4-bit quantization.

Which model should I use?1.5B or 3B for laptops, 7B for daily work, 14B or 32B when you have a GPU with 16–24 GB or more. See Models.

3. Ask for Pharo code

Be specific about class names, selectors and behaviour. For example:

ollama run pharo-llm/pharo-coder:7b 'Create a class LimitedStack with new: capacity, push:, pop, top, isEmpty and isFull. push: on a full stack must signal an Error.'

The model answers with complete code in one smalltalk block: class definitions first (fluid syntax), then each method as ClassName >> selector, then a short explanation and a Playground example.

4. Load the code in Pharo

Paste the class definition into a System Browser to create the class, then each method into the class's method pane. Or ask the model for a Tonel file and load it with Iceberg.
