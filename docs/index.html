What is Pharo-Coder?

Pharo-Coder is a family of open-weight, instruction-tuned assistants specialised for Pharo, for questions, code and agents. They are built on the Qwen2.5-Coder family, continue pre-training on Pharo code, and are fine-tuned on conversations whose code was executed and verified in real Pharo images.

  • Answer questions about the Pharo language, class library, tools (Iceberg, Metacello, SUnit, debugger) and ecosystem.
  • Work as an agent: call tools in a loop (evaluate, define, browse, implementors, run tests) until the task is done. See Agents & tool use.
  • Write classes, methods and extension methods in modern Pharo (fluid class definitions, idiomatic collection protocol).
  • Fix bugs from code and error messages, explain unfamiliar code, write SUnit tests.
  • Translate Python, Java or JavaScript to idiomatic Pharo.
