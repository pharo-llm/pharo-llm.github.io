Use the models

Inside Pharo

Call Pharo-Coder from Pharo code through Ollama's HTTP API.

ChatPharo

ChatPharo brings a chat assistant into the Pharo IDE. Select the Ollama provider in its settings and enter a Pharo-Coder model name, e.g. pharo-llm/pharo-coder:mini.

Plain Zinc + STON

This works in a fresh Pharo image with nothing else installed (tested on Pharo 14):

| body response answer |
body := STONJSON toString: (Dictionary new
	at: 'model' put: 'pharo-llm/pharo-coder:mini';
	at: 'stream' put: false;
	at: 'messages' put: { Dictionary new
		at: 'role' put: 'user';
		at: 'content' put: 'Write Integer >> isPerfectNumber';
		yourself };
	yourself).
response := ZnClient new
	url: 'http://localhost:11434/api/chat';
	entity: (ZnEntity with: body type: ZnMimeType applicationJson);
	timeout: 120;
	post.
answer := ((STONJSON fromString: response) at: 'message') at: 'content'.
answer inspect
