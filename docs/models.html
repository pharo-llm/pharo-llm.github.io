How Pharo-Coder models are organised, named and versioned.

Sizes

The parameter count is part of the name, like Qwen and Llama. All sizes have the same abilities (questions, code, debugging, tool use, agents); larger ones are more accurate.

Versions

  • Minor versions (1.0 → 1.1) are refreshes with new data and improved fine-tuning on the same recipe and base model.
  • Major versions (1.x → 2.0) change the base model family or the training recipe.
  • Snapshots are dated releases within a version. Every snapshot passes the release gate: it must beat its base model on PharoEval.
