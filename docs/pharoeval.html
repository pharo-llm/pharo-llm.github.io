PharoEval

An execution-based benchmark for Pharo code generation.

What it measures

PharoEval v1 has 66 hand-written problems in 14 categories: basics, strings, collections, algorithms, object-oriented design, blocks, exceptions, streams, idioms, bug fixing, translation from Python/Java, reflection, SUnit test writing, and advanced data structures (30 easy, 29 medium, 7 hard).

How a solution is scored

  1. The answer's code blocks are parsed (fluid, legacy and Tonel class definitions and methods are all accepted).
  2. A fresh headless Pharo image is started; classes are created and methods compiled. Undeclared variables or syntax errors fail the problem. Redefining existing system classes is refused.
  3. Each test is a Pharo expression that must evaluate to true, with a timeout. The problem counts as solved only if all tests pass.

We report pass@1 with greedy decoding, the compile rate, and the fraction of individual tests passed.

Quality controls

  • Every reference solution is verified to pass in Pharo.
  • Every problem is verified to fail with an empty answer. Error tests check that the error is not just MessageNotUnderstood, and no selector already exists in the image.
  • All training data is decontaminated against PharoEval (exact prompt match and 13-gram overlap with the reference solutions).

Agent track: PharoEval-Agent

The same problems are also solved through the Pharo tool loop (evaluate, define, browse_class, method_source, implementors, senders, search_classes, run_tests; up to 12 steps). The code the agent built during the session plus its final answer is scored with the same hidden tests. We also report the average number of tool calls and how often the agent finishes on its own.

Example problem

- id: oop/bounded-stack
  prompt: Implement a class `LimitedStack` with class-side constructor `new: capacity`, and instance
          methods `push:` (answers the pushed object, signals an Error when full), `pop` ...
  tests:
    - "| s | s := LimitedStack new: 2. s push: 1; push: 2. s pop = 2 and: [s size = 1]"
    - "[(LimitedStack new: 3) pop. false] on: Error do: [:e | (e isKindOf: MessageNotUnderstood) not]"

Run it yourself

pip install -e "git+https://github.com/pharo-llm/pharo-one#egg=pharo-one"
pharo-one eval --config configs/pharo-coder-1.0-7b.yaml --name "my model" \
  --openai-model pharo-llm/pharo-coder:7b --base-url http://localhost:11434/v1
