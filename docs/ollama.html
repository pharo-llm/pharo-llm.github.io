Ollama

The easiest way to run Pharo-Coder on your own machine.

Pull and run

ollama pull pharo-llm/pharo-coder:7b
ollama run pharo-llm/pharo-coder:7b

OpenAI-compatible API

Ollama exposes an OpenAI-compatible endpoint, so any OpenAI client works:

from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
r = client.chat.completions.create(
    model="pharo-llm/pharo-coder:7b",
    messages=[{"role": "user", "content": "Write Integer >> isPerfectNumber"}],
    temperature=0.2,
)
print(r.choices[0].message.content)

Recommended settings

The published models already include the chat template, the Pharo-Coder system prompt and these defaults: temperature 0.2, top_p 0.95, num_ctx 8192. Raise num_ctx (up to 32768) when you paste large classes:

ollama run pharo-llm/pharo-coder:7b
>>> /set parameter num_ctx 16384
