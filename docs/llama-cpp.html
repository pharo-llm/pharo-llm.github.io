llama.cpp & GGUF

Quantized builds for CPUs, Apple Silicon and small GPUs.

Files

QuantizationQualityUse when
Q4_K_MGood (default)Most machines
Q5_K_MBetterA little more memory available
Q8_0Near-losslessPlenty of memory

The default quantization of every release is re-evaluated on PharoEval through Ollama before it is published; a release is blocked if it loses more than 5 points against bf16.

Run with llama.cpp

# download + run directly from Hugging Face
llama-cli -hf pharo-llm/Pharo-Coder-1.0-Mini-7B-Instruct-GGUF:Q4_K_M -cnv

# or serve an OpenAI-compatible API
llama-server -hf pharo-llm/Pharo-Coder-1.0-Mini-7B-Instruct-GGUF:Q4_K_M --ctx-size 16384 --port 8080

Use a GGUF file with Ollama

FROM ./Pharo-Coder-1.0-Mini-7B-Instruct-Q4_K_M.gguf
TEMPLATE """{{{{- if .System }}}}<|im_start|>system
{{{{ .System }}}}<|im_end|>
{{{{ end }}}}{{{{- range .Messages }}}}<|im_start|>{{{{ .Role }}}}
{{{{ .Content }}}}<|im_end|>
{{{{ end }}}}<|im_start|>assistant
"""
PARAMETER stop <|im_end|>
PARAMETER temperature 0.2
Always set the chat templateA GGUF imported without its ChatML TEMPLATE will not follow instructions (it tends to echo the prompt). The official Ollama builds include it.
