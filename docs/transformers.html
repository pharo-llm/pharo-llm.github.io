Use the models

Transformers & vLLM

Use the safetensors weights on GPUs.

Transformers

pip install -U transformers accelerate torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "pharo-llm/Pharo-Coder-1.0-7B-Instruct"
tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id, dtype="auto", device_map="auto")

messages = [{"role": "user", "content": "Create a Pharo class SavingsAccount with deposit:, withdraw: and balance."}]
inputs = tok.apply_chat_template(messages, add_generation_prompt=True, return_tensors="pt").to(model.device)
out = model.generate(inputs, max_new_tokens=1024, do_sample=False)
print(tok.decode(out[0][inputs.shape[1]:], skip_special_tokens=True))

The chat template inserts the Pharo-Coder system prompt automatically when you don't provide one.

vLLM (OpenAI-compatible server)

pip install vllm
vllm serve pharo-llm/Pharo-Coder-1.0-7B-Instruct --max-model-len 32768
curl http://localhost:8000/v1/chat/completions -H "Content-Type: application/json" -d '{
  "model": "pharo-llm/Pharo-Coder-1.0-7B-Instruct",
  "messages": [{"role": "user", "content": "Write String >> isPalindromeIgnoringCase"}]
}'

Fine-tuning further

The -Base checkpoints are the best starting point for your own instruction tuning; the -Instruct checkpoints for light domain adaptation (e.g. LoRA on your company's Pharo code).
