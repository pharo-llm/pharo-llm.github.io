Why Pharo-Coder

Verified by execution

Every training answer was installed in a fresh Pharo image, compiled, and had its tests run. Hallucinated classes and methods are filtered out before training.

Ask it anything about Pharo

Concepts, the class library, Iceberg, Metacello, SUnit, the debugger, Spec — answers grounded in real Pharo documentation and the image's own class comments.

Built for agents

Native tool calling. Pharo-Coder evaluates code, defines classes, browses the image, finds implementors and runs tests in a loop — trained on agent runs that were verified by hidden tests.

Speaks modern Pharo

Fluid class definitions, idiomatic collection protocol, SUnit tests, and the Pharo image's own conventions — learned from the image and permissively licensed GitHub projects.

Runs on your machine

From 1.5B for laptops to 32B for workstations. Quantized GGUF builds for Ollama and llama.cpp, safetensors for Transformers and vLLM.

Measured honestly

PharoEval scores come from running each answer against unit tests in Pharo. A release only ships if it beats its base model.

Refreshed continuously

A fully automated pipeline mines, trains, evaluates and publishes new snapshots. Pin a dated snapshot or follow the alias.

Open weights

Weights, benchmark and pipeline are open. Training data comes only from MIT and permissively licensed code.
