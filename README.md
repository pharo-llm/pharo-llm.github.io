# pharo-llm.github.io

The Pharo-LLM platform website: model catalog, model pages, model comparison, documentation and
the Pharo-Coder technical report. Static site (no build step), served by GitHub Pages.

| Path | Content |
|---|---|
| `index.html` | Platform home (featured models, quickstart, projects) |
| `models.html` | Model catalog with filters + all model IDs/snapshots |
| `model.html?id=<model-id>` | Model page (ratings, specs, quickstart, PharoEval, snapshots, downloads) |
| `compare.html?model=a&model=b` | Side-by-side comparison of up to 3 models |
| `docs/*.html` | Documentation (sidebar + "on this page" layout) and the technical report |
| `data/models.json` | **Single source of truth** for all models. Written automatically by the `pharo-one` release pipeline (`site` stage) |
| `reports/*.md` | Per-release technical reports generated by the pipeline |
| `assets/app.css`, `assets/app.js` | Design system and all page renderers |

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000
(pages fetch `data/models.json`, so opening the files directly with `file://` will not work).
